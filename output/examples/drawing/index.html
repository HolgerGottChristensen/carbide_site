Accent
\n
\n
The accent example shows how to change the accent color of the Environment, when rendering. The environment is inherited by a widget's children, and is following the normal scoping rules.
\n
Explanation
\n
When rendering, unless otherwise specified, shapes uses the accent color from the environment to fill the shape.
\n
The accent color of the environment can be overridden using the .accent_color() modifier. This modifier can be applied to any widget. The modifier takes anything that can be turned into a State of Color. This is for example a static Color, EnvironmentColor and others.
\n
Below we see the source code of the example:
\n
fn main() {\n    let mut application = Application::new();\n\n    application.set_scene(\n        Window::new(\n            "Accent example - Carbide",\n            Dimension::new(600.0, 600.0),\n            VStack::new((\n                Rectangle::new()\n                    .frame(100.0, 30.0),\n                Rectangle::new()\n                    .frame(100.0, 30.0)\n                    .accent_color(RED),\n                Rectangle::new()\n                    .frame(100.0, 30.0)\n                    .accent_color(EnvironmentColor::Red)\n            )).accent_color(GREEN)\n        )\n    );\n\n    application.launch()\n}
\n
We start by creating an Application, and setting the Scene of that application. The scene consist of a single Window.
\n
The content of the window is a VStack, which has three rectangles.
\n
The .accent_color() modifier is used in three different places. It is applied to the VStack, which affects all its children. This is why the first rectangle is green.
\n
The second modifier is applied to the second rectangle. This overrides the accent color and sets it to the color red, which we see in the result.
\n
The third modifier is applied to the third rectangle, and is using the EnvironmentColor red. Since this is an environment specific color, it is not pre determined, but can change based on the Theme and overridden.
\n
Run the example
\n
The example can be run with the following command: cargo run --package carbide_wgpu --example accent when located in the working directory carbide.
\n
For better performance, remember to run the example with --release.

Blur
\n
\n
The blur example shows how to apply a blur rendering effect within a given shape to an area. In the example, we blur an Image within specified moving areas with different blur strengths.
\n
Explaination
\n
Carbide provides different graphical effects (Filter) that can be used to customize rendering and style your application to your liking. The blur example consist of two shapes, within which a gaussian or box blur is applied.
\n
Another place blurring is used, is for rendering specific materials.
\n
In the below code, a mean/box blur effect is given, and clipped to a circle. The effect is constrained to a 100x100 frame, and offset with an x coordinate.
\n
Blur::mean(3)\n    .clip_shape(Circle::new())\n    .frame(100.0, 100.0)\n    .offset(position_neg_x.clone(), 0.0),
\n
The offset of the blur effect is animated, to show how the effect is dynamic, and performant.
\n
When multiple blur effects overlap, the are applied on top of each other, making a stronger blur. Using the WGPU rendering backend, the blurs are calculated on the GPU, with different rendering performance optimizations, to allow larger radii blurs. But when the blur radii become very large, they can be taxing on the GPU, and it is recommended to apply multiple blurs on top of each other instead.
\n
Both Gaussian and Box blurs stack, and the same rendering result can be achieved by combining multiple blurs with a smaller radius instead of a single blur with a large radius.
\n
Run the example
\n
The example can be run with the following command: cargo run --package carbide_wgpu --example blur when located in the working directory carbide.
\n
For better performance, remember to run the example with --release.

Explaination
\n
When rendering an Image, you can derine the image to be rendered in icon mode. When rendering in icon mode, the color of the result is defined by the Label EnvironmentColor.
\n
VStack::new((\n    Image::new_icon("images/rust.png")\n        .foreground_color(EnvironmentColor::Accent),\n    Rectangle::new()\n        .frame(50.0, 50.0),\n)).accent_color(EnvironmentColor::Green)
\n
In the above code, we define a VStack with 2 elements. The first element in the stack is an Image that is defined to render in icon mode. The Label EnvironmentColor is set to the current Accent EnvironmentColor. The second element is a 50x50 rectangle, which by default is rendered using the accent color. Lastly the accent color is set to the EnvironmentColor green for all items in the VStack.
\n
\n
The default color used for the icon is the Label EnvironmentColor. This is chosen because you often want the same color to be used for the icons as the current Text color. The default Text color is also using the Label EnvironmentColor.
\n
\n
Run the example
\n
The example can be run with the following command: cargo run --package carbide_wgpu --example icon when located in the working directory carbide.
\n
For better performance, remember to run the example with --release.
